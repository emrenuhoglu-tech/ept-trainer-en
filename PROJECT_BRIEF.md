# EPT Trainer
Target: 10 August 2026 (EPT Barcelona 16 August). Single user: Emre. Deploy: localhost + phone. (English build.)

## Modes
1. Lessons — 9 modules, slides + spoken coach narration
2. Quiz — Range / Scenario / Run (offline, from the book)
3. Drill / Table — Socratic Q&A + hand simulator, Claude API live coach
4. Progress — scorecard + spaced repetition, review, decision journal
5. Reference — Range Guide, Bet Types, Question Bank, 15 Sentences, Equity

## Modules (source: content/poker_pocket_book_v5.md)
M1 Root error (Chapter 0+7) · M2 Bluff selection & board ownership (Chapter 1) · M3 Deceptive medium hands (Chapter 2) · M4 Stack modes & ICM (Chapter 3) · M5 3-bet & call ranges (Chapter 4★) · M6 4-bet — response to a 3-bet (Chapter 4.5) · M7 25–30bb band (Chapter 5★) · M8 Draws on the turn (Chapter 6) · M9 PLO fundamentals (Chapter 8)

## Phases
Phase 1: skeleton + Quick Reference + Lessons (Web Speech)
Phase 2: Drill Mode + scorecard + spaced repetition
Phase 3 (opt.): ElevenLabs voice, vertical mp4 export via Remotion

## Acceptance criteria
- On a phone, the M5 lesson plays with voice; picking a position in the table highlights the range
- An 8-question drill session completes; a wrong answer returns the next day in a different disguise
- Quick Reference fits on one screen
